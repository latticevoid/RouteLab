## ✨ About

**PathForge** is an interactive pathfinding visualizer that demonstrates how popular graph search algorithms explore a grid and discover the shortest path.

Draw obstacles, place start and end nodes, choose an algorithm, and watch each step animate in real time. PathForge is designed to make algorithms easier to understand through visualization.

---

## 🚀 Features

| | |
|:--|:--|
| 🟢 **Interactive Grid** | Draw and erase walls with your mouse |
| 📍 **Movable Nodes** | Place custom start and end positions |
| 🧠 **Multiple Algorithms** | BFS, DFS, Dijkstra, and A* |
| ⚡ **Animated Search** | Watch every visited node in real time |
| 🎲 **Random Maze Generator** | Generate unique obstacle layouts |
| 🎛 **Speed Controls** | Slow down or speed up animations |
| 🧹 **Clear Grid** | Reset the board instantly |
| 📱 **Responsive Design** | Works on desktop and mobile |

---

## 🧠 Algorithms

Currently supported algorithms include:

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Dijkstra's Algorithm
- A* Search

Each algorithm behaves differently, allowing users to compare their efficiency and search strategies visually.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/LatticeVoid/PathForge.git
cd PathForge
```

Open `index.html` in your browser.

No additional dependencies are required.

---

## 💡 Usage

1. Place a **Start** node.
2. Place an **End** node.
3. Draw walls on the grid.
4. Select a pathfinding algorithm.
5. Press **Start**.
6. Watch the algorithm search for the shortest path.
